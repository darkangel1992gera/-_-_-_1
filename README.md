# Random Quote Generator
Генератор случайных цитат с историей и фильтрацией.
## Автор
Мешков Вадим Олегович
## Описание
Приложение **Random Quote Generator** — это десктопное GUI‑приложение на Python, которое:
* генерирует случайные цитаты из предопределённого списка;
* отображает историю сгенерированных цитат;
* позволяет фильтровать цитаты по автору и теме;
* сохраняет историю и базу цитат в JSON‑файл между запусками;
* проверяет корректность ввода данных.
## Функциональность
* **Генерация цитаты**: кнопка «Сгенерировать цитату» выбирает случайную цитату из списка (с учётом фильтров).
* **История**: все сгенерированные цитаты отображаются в прокручиваемом списке с нумерацией.
* **Фильтрация**:
    * по автору (выпадающий список);
    * по теме (выпадающий список).
* **Сохранение данных**: история и список цитат сохраняются в файл `quotes_data.json`.
* **Управление историей**: кнопки для очистки истории и ручного сохранения данных.
* **Валидация**: проверка на пустые строки при добавлении новых цитат (в текущей реализации — защита от отсутствия цитат).
## Технологии
* Python 3.x
* Tkinter — для графического интерфейса
* JSON — для сохранения и загрузки данных
